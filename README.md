# 重理课表

个人开发的 Android 校园课表工具，目前为试用版。

[下载安装包](https://github.com/nfub/cqut-schedule-releases/releases/latest)

## 使用

1. 下载最新发行版中的 `cqut-schedule-版本号.apk`，在手机系统界面确认安装。
2. 打开应用，连接学校课表并在学校页面登录自己的账号。
3. 应用读取本学期全部课表，保存后可离线查看；左右滑动切周，点课程看详情。
4. 调课后点首页“刷新”。不定时自动联网更新课表。
5. 进入“设置 → 应用更新 → 检查更新”，发现新版后下载并确认安装，无需连接电脑。

最低 Android 8.0。已有课表在覆盖安装后保留。早期版本没有 GitHub 更新地址，需从这里手动安装一次新版，之后可以在应用内更新。

## 数据

学校登录在学校 HTTPS 页面完成。课表与学校会话保存在使用者自己的手机中，不发送到 GitHub；本仓库只提供安装包、版本信息和说明。

## 当前范围

面向校园小范围试用。不同学校账号类型、手机和网络仍需逐步验证；GitHub 下载速度取决于使用者的网络。若暂时无法联网更新，已保存的课表仍可查看。

每个发行版附带 SHA256SUMS.txt 和 update.json。应用内下载还会检查包名、版本、签名和安装包完整性。
